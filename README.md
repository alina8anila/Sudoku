Гра в судоку, створює судоку, за потреби може підказати чи розв'язати його. Матиме кілька рівнів складності. При кожному неправильному ході (після якого судоку стає таким, яке неможливо розв'язати) втачається одне "життя"

Можливості:
-можна вибрати рівень складності
-підсвічує цифри які ти вибрав 
-може зберегти судоку у pdf файл
-дає підказки
-є режим нотаток

Парадигми:

    1. ООП: Клас SudokuGrid для сітки 9x9. Клас Solver з різними алгоритмами (constraint satisfaction, constraint propagation). Клас Generator для створення нових головоломок.

    2. Функціональне програмування: Рекурсивний constraint satisfaction для розв'язання. Filter для пошуку порожніх клітинок. Map для оновлення сету possible після додавання/видаляння якоїсь клітинки.

    3. Логічне програмування: Prolog для перевірки чи можна в цю клітинку вставити це (конкретне) число: 
        "Кожне число від 1 до 9 з'являється рівно раз у кожному рядку/стобчику/блоці"


Встановлення
1. Клонуйте репозиторій
`git clone https://github.com/ukma-cs-pl-2025/labs-alina8anila`
`cd labs-alina8anila/final_project`
2. Встановіть залежності: `pip install -r requirements.txt`
3. Запустіть: `python3 front.py`
Потрібен Python 3.10+

Використання
1. Запустіть застосунок: `python3 front.py`
2. Відкриється головне вікно з ігровим полем
3. Клікайте на вільну клітинку і клавіатурою вписуйте цифру (1-9)
4. Використовуйте кнопки з цифрами, щоб під світити і краще бачити їх
5. Щоб вписати цифру, в якій ви ще не впевнені і не отримати "мінус життя" включить режим "note"
6. Щоб вибрати рівень оберіть level на "Радіокнопці" ліворуч
7. Щоб зіграти ще раз натисніть "new game"/"play again"/"try again"
